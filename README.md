# 🛍️ Customer Shopping Analysis

## 📌 Project Overview

The **Customer Shopping Analysis** project focuses on analyzing customer shopping behavior to uncover insights into purchasing patterns, product preferences, customer demographics, and shopping trends.

The project involves cleaning and preparing raw customer shopping data using **Microsoft Excel** and transforming it into meaningful insights through data analysis and visualization in **Microsoft Power BI**.

The goal is to understand customer behavior, identify shopping trends, and present actionable insights that can help businesses make data-driven decisions.

## 🎯 Project Objectives

- Analyze customer purchasing behavior and shopping patterns.
- Understand customer demographics based on age and gender.
- Explore product category preferences and purchase amounts.
- Identify seasonal shopping trends.
- Analyze customer reviews and ratings.
- Understand subscription status and purchase frequency.
- Examine payment methods and shipping preferences.
- Investigate the use of discounts and promotional codes.
- Build an interactive Power BI dashboard for business insights.

## 📂 Dataset Description

The dataset contains customer shopping information, including demographic details, purchase history, product preferences, and transaction-related attributes.

### Key Dataset Columns

| Column Name | Description |
|---|---|
| Customer ID | Unique identifier for each customer |
| Age | Age of the customer |
| Gender | Gender of the customer |
| Item Purchased | Product purchased by the customer |
| Category | Category of the purchased product |
| Purchase Amount (USD) | Amount spent on the purchase |
| Location | Customer's location |
| Size | Size of the purchased item |
| Color | Color of the purchased item |
| Season | Season associated with the purchase |
| Review Rating | Customer's product review rating |
| Subscription Status | Indicates the customer's subscription status |
| Shipping Type | Shipping method selected |
| Discount Applied | Indicates whether a discount was applied |
| Promo Code Used | Indicates whether a promotional code was used |
| Previous Purchases | Number of previous purchases |
| Payment Method | Payment method used |
| Frequency of Purchases | How frequently the customer makes purchases |

## 🧹 Data Cleaning & Preparation

Data cleaning was performed using Microsoft Excel to improve data quality and ensure the dataset was suitable for analysis.

The following steps were carried out:

1. **Removed duplicate records** to avoid repeated entries.
2. **Handled missing values** to improve data completeness.
3. **Corrected inconsistent formats** across dataset columns.
4. **Standardized text and category names** for consistent analysis.
5. **Filtered and sorted records** to make the dataset easier to inspect.
6. **Validated data types** to ensure numeric and categorical fields were correctly represented.
7. **Checked invalid values** to identify inconsistencies that could affect the analysis.

After cleaning, the prepared dataset was used for further analysis and visualization in Power BI.
